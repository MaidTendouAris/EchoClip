# 启动行为与保存格式（0.8.0+15）

## 录音目录

打开应用只读取现有目录，不再弹出目录选择器。没有配置目录时，点击录音键先提示选择目录；取消后不启动采集，选定有效目录后继续录音。设置页仍可随时更改目录。

## 平台启动行为

- Android 设置页显示“当前平台暂不支持开机自启”，关闭并禁用该开关，隐藏启动动作和静默启动入口。
- Android 不再发出启动通知或为启动动作请求权限。兼容清理会关闭旧启动配置并取消旧通知；普通定时任务的开机后闹钟恢复仍保留，不作为应用开机自启功能。
- Windows 启用开机自启后，才可以启用静默启动。关闭自启会同时清除静默设置。
- 自启命令为带引号的可执行文件加 --autostart；静默时增加 --silent。原生首帧和 Flutter 都不展示窗口，托盘仍可打开窗口；手动启动正常显示。重复的静默启动不唤醒已有窗口。托盘初始化失败时显示窗口，避免应用不可访问。
- 设置持久化到现有 Windows 配置，不替用户启用系统自启。自动化验证没有修改用户注册表。

## 保存格式

支持 MP3（默认）、FLAC、OGG/Vorbis、WAV、M4A/AAC、AAC/ADTS。设置用于主页、快捷键及 Android 通知等手动保存，定时任务继续使用各自保存的格式，编辑器也支持以上六种格式。格式和对应文件扩展名、Android MIME / 分享类型保持一致。

两端 FFmpeg 均补入内建 Vorbis 编码器、解码器和 OGG 封装/解封装。OGG 使用 FFmpeg 内建 Vorbis，单声道输入经重采样器复制为其要求的双声道；不引入额外编码库。M4A 和 AAC 使用 FFmpeg AAC，MP3 使用已有 LAME，FLAC 为无损编码，WAV 输出 16-bit PCM。应用所有手动保存都经 FFmpeg；核心无 FFmpeg 的旧 WAV 接口继续兼容。

## WAV 边界

界面明确提示单个 WAV 不可超过 4 GB、每次最多保存 4 小时。预设时长不超过 4 小时；自定义区间可以位于整段缓存中的任意位置，但长度不超过 4 小时，支持拖动和时/分/秒输入。切换到 WAV 时，已有超长选择调整为 4 小时预设。

手动保存入口、Android 保存任务、定时任务校验和 Rust 核心均防止超长 WAV；核心同时保留 RIFF 字节大小校验。其他格式仍支持最长 24 小时选择。

## 验证范围

- Flutter 完整回归覆盖首次启动不弹目录、录音前选择/取消、Android 禁用入口、静默启动依赖及清除、多格式下拉框和 WAV 区间限制。
- Rust 回归覆盖 WAV 4 小时边界、RIFF 容量、定时任务格式限制以及静默命令参数。
- 实际 Windows Rust DLL 调用新版 FFmpeg，六种格式均验证 16 kHz / 44.1 kHz 的编码和解码。WAV/FLAC PCM 逐样本一致；有损编码按容器允许编码器填充。
- Android JVM 回归及正式包签名、版本和原生库校验另见 HANDOFF_GPT6_ASTRA.md。尚未执行物理设备重启或 Android 真机端到端格式导出。
